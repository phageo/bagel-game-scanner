This repository holds no code of other projects. What it holds about other projects:

- Hash tables in gamescan/ (engine_hashes, compiled_hashes, library_hashes, electron_official,
  inno_official, nsis_official, directx_official, npm_hashes and their .bin files): SHA-256
  values, file names, sizes and version numbers of official, published files - facts about those
  files, written by the builders in tools/ from the publishers' own archives. No file content of
  those archives is stored here. tools/manifest*.json name each archive, its official address,
  its SHA-256 and a short note on its licence (reminders, not legal texts).
- Test fixtures in tests/fixtures_cs, tests/fixtures_msi and tests/fixtures_screnc: built here
  from the project's own harmless inputs with Windows' own tools (the .NET Framework's csc.exe,
  Windows Installer through PowerShell, makecab.exe, the Script Encoder), stored as base64 text
  with their SHA-256 (tests/build_*.py say how each was made).
